# Claude

## 스쿼시 점수판 (`squash/`)

폰·태블릿용 스쿼시 점수판입니다. 아이폰·갤럭시 홈 화면에 설치해 앱처럼 쓸 수 있습니다.

- 주소: https://song940906.github.io/Claude/squash/
- PAR 11 / PAR 15 / 전통식 9점, 서브 박스(R/L), 게임볼·매치볼, 렛, 되돌리기, 휴식 90초·워밍업 5분 타이머
- 설치: 아이폰 Safari → 공유 → 홈 화면에 추가 / 갤럭시 Chrome·삼성 인터넷 → 메뉴 → 홈 화면에 추가

`squash/` 는 생성물입니다. 원본(`squash-scoreboard.html`)을 고친 뒤 `node make.js` 로 다시 만들어 덮어씁니다.
